# Fundamental-Engineering-Mechanical-_-Study-App
Offline FE Mechanical study app featuring 220 practice problems, step-by-step solutions, and randomized quizzes. Based on *FE Mechanical Exams: Two Practice Exams with Step-by-Step Solutions* (2022) by Mohammad Iqbal and Ali A. Iqbal, published by PPI/Kaplan. Independent educational tool; not affiliated with the publisher.

# 👓 FE Mechanical Study App

**An offline desktop study application for Fundamentals of Engineering (FE) Mechanical exam preparation.**

Built with Python and Tkinter, this application provides a simple, distraction-free environment for reviewing engineering practice problems and detailed worked solutions.

## Features

- **220 Practice Problems** — Two complete FE Mechanical practice exams.
- **Step-by-Step Solutions** — View detailed worked solutions for each problem.
- **Randomized Study Mode** — Shuffle questions without repeating them within a session.
- **Sequential Study Mode** — Work through problems in numerical order.
- **Previous & Next Navigation** — Easily revisit questions.
- **Progress Tracking** — Monitor your progress through each study session.
- **Offline Access** — No internet connection required after installation.
- **Windows Desktop Support** — Standalone application with a custom glasses icon.

## Installation

### Windows

1. Open the repository's **Releases** section.
2. Download the latest Windows application ZIP.
3. Extract the ZIP to your preferred location.
4. Open the extracted folder.
5. Double-click `FE-Mechanical-Study.exe` to launch the application.

No Python installation is required for the packaged Windows executable.

## How to Use

1. Launch FE Mechanical Study.
2. Select **Exam 1**, **Exam 2**, or **Both Exams**.
3. Choose sequential or randomized question order.
4. Read the displayed problem and attempt to solve it.
5. Select **Show Solution** to review the worked answer.
6. Navigate using **Previous Problem** and **Next Problem**.

The application is intended for independent, self-paced study.
