WINDOWS QUICK START
1. If supplied as multiple ZIPs, extract ALL parts into the same parent folder.
   Each archive contains the same FE_Mechanical_Study folder; merge folders.
   Do not run files directly inside a ZIP.
2. Install Python 3.11 or 3.12 from https://www.python.org/downloads/.
   Include Tcl/Tk, pip and the Python launcher or Add Python to PATH.
3. Open FE_Mechanical_Study and double-click INSTALL.bat. Internet is required.
4. After successful setup, double-click LAUNCH.bat. Study offline thereafter.
   Keep the folder writable so answer entries can be saved.

FEATURES
220 question/solution pairs, shuffle, navigation, solution zoom, persistent
countdown/stopwatch and editable answer sheet. Answer letters are not a verified
answer key; enter your own verified choices. Optional support link opens a browser.

TROUBLESHOOTING
If setup fails, check the displayed error and Python installation. Use a supported
Python build for your Windows architecture. If Pillow fails, close the app,
delete only the .venv folder in this app folder and rerun INSTALL.bat.
Do not disable antivirus. You can inspect the batch scripts in Notepad.
Windows GUI and installer have not been independently tested on Windows.
