# Fundamental-Engineering-Mechanical-_-Study-App
Offline FE Mechanical study app featuring 220 practice problems, step-by-step solutions, and randomized quizzes. Based on *FE Mechanical Exams: Two Practice Exams with Step-by-Step Solutions* (2022) by Mohammad Iqbal and Ali A. Iqbal, published by PPI/Kaplan. Independent educational tool; not affiliated with the publisher.
